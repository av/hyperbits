## Variables

Theme an embed without editing the bit: put `data-variable-values` on the `data-composition-src` element, or bake new defaults into the installed copy with `--set`.

| Id | Type | Default | Label |
| --- | --- | --- | --- |
| `text` | string | `"Text Transition"` | Text |
| `color` | color | `#fcc192` | Text color |
| `background` | color | `#100f0f` | Background |

```html
<div data-composition-src="compositions/blur-slide-word.html" data-variable-values='{"text":"Text Transition","color":"#fcc192","background":"#100f0f"}'></div>
```

```bash
npx @av/hyperbits add blur-slide-word --into compositions/ --set "background=#0b1020"
```
