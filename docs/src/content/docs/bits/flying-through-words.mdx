## Variables

Theme an embed without editing the bit: put `data-variable-values` on the `data-composition-src` element, or bake new defaults into the installed copy with `--set`.

| Id | Type | Default | Label |
| --- | --- | --- | --- |
| `words` | string | `"GPT,Claude,PaLM,Gemini,LLaMA,Mistral,Mixtral,Falcon,BLOOM,Kimi,MiniMax,Qwen"` | Words (comma separated) |
| `color` | color | `#fcc192` | Word color |
| `background` | color | `#100f0f` | Background |

```html
<div data-composition-src="compositions/flying-through-words.html" data-variable-values='{"words":"GPT,Claude,PaLM,Gemini,LLaMA,Mistral,Mixtral,Falcon,BLOOM,Kimi,MiniMax,Qwen","color":"#fcc192","background":"#100f0f"}'></div>
```

```bash
npx @av/hyperbits add flying-through-words --into compositions/ --set "background=#0b1020"
```
