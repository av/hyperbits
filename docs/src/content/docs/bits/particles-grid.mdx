## Variables

Theme an embed without editing the bit: put `data-variable-values` on the `data-composition-src` element, or bake new defaults into the installed copy with `--set`.

| Id | Type | Default | Label |
| --- | --- | --- | --- |
| `color` | color | `#ffffff` | Cell color |
| `background` | color | `#100f0f` | Background |

```html
<div data-composition-src="compositions/particles-grid.html" data-variable-values='{"color":"#ffffff","background":"#100f0f"}'></div>
```

```bash
npx @av/hyperbits add particles-grid --into compositions/ --set "background=#0b1020"
```
