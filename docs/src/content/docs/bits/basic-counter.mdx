## Variables

Theme an embed without editing the bit: put `data-variable-values` on the `data-composition-src` element, or bake new defaults into the installed copy with `--set`.

| Id | Type | Default | Label |
| --- | --- | --- | --- |
| `prefix` | string | `"width: "` | Prefix |
| `postfix` | string | `"px"` | Postfix |
| `color` | color | `#fcc192` | Text color |
| `background` | color | `#100f0f` | Background |

```html
<div data-composition-src="compositions/basic-counter.html" data-variable-values='{"prefix":"width: ","postfix":"px","color":"#fcc192","background":"#100f0f"}'></div>
```

```bash
npx @av/hyperbits add basic-counter --into compositions/ --set "background=#0b1020"
```
