## Variables

Theme an embed without editing the bit: put `data-variable-values` on the `data-composition-src` element, or bake new defaults into the installed copy with `--set`.

| Id | Type | Default | Label |
| --- | --- | --- | --- |
| `message` | string | `"Hey, did the render finish?"` | First message |
| `color` | color | `#ec8b49` | My bubble color |
| `background` | color | `#100f0f` | Background |

```html
<div data-composition-src="compositions/chat-conversation.html" data-variable-values='{"message":"Hey, did the render finish?","color":"#ec8b49","background":"#100f0f"}'></div>
```

```bash
npx @av/hyperbits add chat-conversation --into compositions/ --set "background=#0b1020"
```
