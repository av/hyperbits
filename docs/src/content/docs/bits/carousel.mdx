## Variables

Theme an embed without editing the bit: put `data-variable-values` on the `data-composition-src` element, or bake new defaults into the installed copy with `--set`.

| Id | Type | Default | Label |
| --- | --- | --- | --- |
| `color` | color | `#fcc192` | Card color |
| `background` | color | `#111111` | Background |

```html
<div data-composition-src="compositions/carousel.html" data-variable-values='{"color":"#fcc192","background":"#111111"}'></div>
```

```bash
npx @av/hyperbits add carousel --into compositions/ --set "background=#0b1020"
```
