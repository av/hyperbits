## Variables

Theme an embed without editing the bit: put `data-variable-values` on the `data-composition-src` element, or bake new defaults into the installed copy with `--set`.

| Id | Type | Default | Label |
| --- | --- | --- | --- |
| `background` | color | `#100f0f` | Background |
| `foreground` | color | `#f2f0e5` | Foreground |
| `accent` | color | `#9d8af0` | Accent |
| `pinwheels` | number | `14` | Pinwheels per row |
| `seed` | number | `5` | Seed |

```html
<div data-composition-src="compositions/pinwheel-grid.html" data-variable-values='{"background":"#100f0f","foreground":"#f2f0e5","accent":"#9d8af0","pinwheels":14,"seed":5}'></div>
```

```bash
npx @av/hyperbits add pinwheel-grid --into compositions/ --set "background=#0b1020"
```
