## Variables

Theme an embed without editing the bit: put `data-variable-values` on the `data-composition-src` element, or bake new defaults into the installed copy with `--set`.

| Id | Type | Default | Label |
| --- | --- | --- | --- |
| `title` | string | `"hyperbits"` | Title |
| `color` | color | `#fcc192` | Accent |
| `background` | color | `#100f0f` | Background |

```html
<div data-composition-src="compositions/feature-showcase.html" data-variable-values='{"title":"hyperbits","color":"#fcc192","background":"#100f0f"}'></div>
```

```bash
npx @av/hyperbits add feature-showcase --into compositions/ --set "background=#0b1020"
```
