## Variables

Theme an embed without editing the bit: put `data-variable-values` on the `data-composition-src` element, or bake new defaults into the installed copy with `--set`.

| Id | Type | Default | Label |
| --- | --- | --- | --- |
| `color` | color | `#ebb03b` | Spark color |
| `background` | color | `#100f0f` | Background |

```html
<div data-composition-src="compositions/particles-fountain.html" data-variable-values='{"color":"#ebb03b","background":"#100f0f"}'></div>
```

npx @av/hyperbits add particles-fountain --into compositions/ --set "background=#0b1020"
