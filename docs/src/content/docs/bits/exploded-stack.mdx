## Variables

Theme an embed without editing the bit: put `data-variable-values` on the `data-composition-src` element, or bake new defaults into the installed copy with `--set`.

| Id | Type | Default | Label |
| --- | --- | --- | --- |
| `layers` | string | `"Interface,Timeline,Helpers,Renderer,Frames"` | Layers, top to bottom, comma separated |
| `background` | color | `#100f0f` | Background |
| `foreground` | color | `#f2f0e5` | Line ink |
| `accent` | color | `#ec8b49` | Accent |

```html
<div data-composition-src="compositions/exploded-stack.html" data-variable-values='{"layers":"Interface,Timeline,Helpers,Renderer,Frames","background":"#100f0f","foreground":"#f2f0e5","accent":"#ec8b49"}'></div>
```

```bash
npx @av/hyperbits add exploded-stack --into compositions/ --set "background=#0b1020"
```
