## Variables

Theme an embed without editing the bit: put `data-variable-values` on the `data-composition-src` element, or bake new defaults into the installed copy with `--set`.

| Id | Type | Default | Label |
| --- | --- | --- | --- |
| `lines` | string | `"First sentence.\|Second longer sentence.\|Looping..."` | Sentences (\| separated) |
| `color` | color | `#fcc192` | Text color |
| `background` | color | `#100f0f` | Background |

```html
<div data-composition-src="compositions/multi-text-typewriter.html" data-variable-values='{"lines":"First sentence.|Second longer sentence.|Looping...","color":"#fcc192","background":"#100f0f"}'></div>
```

```bash
npx @av/hyperbits add multi-text-typewriter --into compositions/ --set "background=#0b1020"
```
