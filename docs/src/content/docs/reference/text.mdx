---
title: text
description: Split text into spans and drive typewriter reveals
---

Split an element's text into character, word, or line spans, then reveal them over time.

```js
import { splitText, typewriter, applyTypewriter } from "hyperbits/helpers";

const spans = splitText(title, "chars");
timeline.to({}, {
  duration: 2,
  onUpdate() {
    applyTypewriter(title, timeline.time(), { duration: 2 });
  },
});
```

## Split

`splitUnits(text, mode)` returns strings. `splitText(element, mode)` wraps them in spans (`white-space: pre`). Modes: `"chars"` (default), `"words"`, `"lines"`. Character spans get `data-char`. Newline units use `display: block` so wrapped typewriter text stays on separate lines; other units use `inline-block`.

## Typewriter

`charsVisibleAt(time, { total, duration, delay? })` returns how many units should show.

`applyTypewriter(element, time, { duration, delay? })` splits if needed and hides unrevealed spans with `display: none` so a caret placed after the typed element sits against the last visible character.

`typewriter(element, options)` splits once and returns `{ apply, spans }`.
