# Hyperbits documentation

Documentation site for [hyperbits](../README.md). Built with [Astro](https://astro.build/) + [Starlight](https://starlight.astro.build/).

```bash
npm install
npm run docs:dev
```

Visit `http://localhost:4321`. `npm run docs:build` writes `docs/dist/` for Cloudflare Pages. Deploy with `scripts/deploy-docs.sh`.
