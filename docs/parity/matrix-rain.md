# matrix-rain

Category: text-animations. Fidelity 2 -> 5 (1-5, judged against the remotion-bits original rendered side by side).

Was: 36px+ canvas glyphs, katakana set, random per-column speeds and lengths that never matched the original streams.
Now: MatrixRain's model: 30px cells, per-column speed/offset seeds, 15 glyph tails with linear falloff, white bold glowing heads, 4 frame glyph cycling, and the original charset. Streams and glyphs are identical; only the monospace face differs (Geist Mono vs the reference render's fallback).
