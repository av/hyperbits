# scrolling-columns

Category: particles. Fidelity 1 -> 5 (1-5, judged against the remotion-bits original rendered side by side).

Was: four flat 2D columns scrolling at fixed speeds.
Now: four particle-driven card streams (speeds 4/7/5/6, z 50/0/100/-50, 15 colours, 288px cards) inside a Scene3D whose camera eases (easeIn, double-eased like remotion) from the start to the end step over 300 frames. Diff 0.0 at every checkpoint.
